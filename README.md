# Лабораторная работа № 1 — Git

## Цель
Освоить создание коммитов и веток, слияние изменений, обнаружение и ручное разрешение конфликта, а также публикацию репозитория на GitHub.

## Выполнено
1. Создан репозиторий с основной веткой `main`.
2. Добавлены `file1.txt` и `file2.txt`, изменения сохранены коммитами.
3. Создана ветка `feature`; изменения в ветке объединены с `main` посредством fast-forward.
4. В двух ветках независимо изменён `file1.txt`; при слиянии воспроизведён конфликт.
5. Конфликт разрешён вручную, итоговое состояние зафиксировано merge-коммитом.
6. Проверены граф истории коммитов и чистое состояние рабочей копии.
7. Подготовлен отчёт со скриншотами выполненных команд.

## Структура
- `file1.txt` — демонстрация независимых изменений и разрешения конфликта.
- `file2.txt` — демонстрация изменений в рабочей ветке.
- `Отчет.pdf` — отчёт с подтверждающими скриншотами.
